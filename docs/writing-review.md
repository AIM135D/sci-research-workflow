# 写作、翻译与审查

## 先确定材料和范围

作者应提供要处理的段落、真实结果或证据，明确语言、目标读者、希望修改的范围，以及是否只允许诊断。论文写作由一个写作负责人组织，其他审查工具提供意见；这样可以减少多个写作流程对同一段反复改写造成的含义漂移。

| 请求 | 工作方式 | 需要保留 |
| --- | --- | --- |
| 中文段落润色 | 改善主语、逻辑和术语表达 | 数据、引用、条件、否定和结论力度 |
| 英文段落润色 | 调整语法、衔接和学科表达 | 比较方向、限定、证据强度和真实限制 |
| 中译英 | 先译准，再单独检查英文学术表达 | 源文的公式、单位、引用和限定 |
| 直译 | 以准确对应为目标 | 用户要求保留的形式和措辞 |
| 审稿意见回复 | 逐条核对评论、作者证据和实际修改 | 未完成事项的真实状态 |
| 只读审查 | 指出位置、证据、影响及建议 | 原稿保持不变 |

SCI 论文起草和改写默认先交付用户请求的中文内容。用户明确要求英文、翻译或直译时按该请求执行，不强迫另写一份中文稿。最终文章的内容和署名由作者负责。

## 主张为什么需要和证据对应

一项结论至少包括研究对象、方法、对照、指标、结果和适用条件。润色或压缩时，如果删掉其中的条件，读者可能把局部观察理解为普遍结论。例如，“在测试数据集上延迟下降，但准确率下降”的句子，不能改成“全面提升性能”。这个示例是虚构的文字练习，不代表真实实验。

对于翻译，除了数值和单位，还要检查“约”“仅”“不超过”“未发现”等词，比较方向，以及数据集、模型、图表和文献引用。图中的标签、正文中的缩写与表格中的列名需要与作者材料对应。无法确认的地方，保留原意并向作者提出具体问题。

## 直接表达与完整报告

删除重复的铺垫、空泛形容词和没有依据的强调，使读者更容易找到问题、方法和结果。支持结论的证据、合理的统计不确定性、负面结果、限制条件、伦理审批和要求披露的 AI 使用应如实保留。不同结果之间的权衡需要有数据或来源，不能为了叙述流畅自行补充原因。

## 审查不是自动改稿

`sci-peer-review` 应先说明实际读过哪些材料，再对可以定位的问题提出意见。每个重要意见至少包括：稿件位置、观察到的证据、为什么影响结论，以及需要作者提供或检查什么。引用核验要区分书目正确和内容支持，摘要不可替代全文分析。

期刊委托审稿和作者自查属于不同场景。未公开稿件、审稿意见或保密文件只有在授权和相关政策允许时才可交给当前工具处理；不得擅自上传到额外的检索、语言或模型服务。模型生成的审查意见是草稿，负责人应核对并自行决定如何使用。
