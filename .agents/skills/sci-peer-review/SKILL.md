# SCI 论文只读审查

确认审查范围、材料、读者身份和目标期刊（如有）；对未公开第三方稿件，先确认有权使用当前工具且符合期刊保密和 AI 政策。未经相应许可，不向外部服务发送稿件、审稿意见或未公开研究内容。不能访问、不能核实或超出专业范围的内容应明确说明。

## 审查流程

1. 提取论文要回答的问题、方法、主要结论、比较对象和作者提供的证据，标出文章或图表位置。没有读到的数据、补充材料和代码标为不可用。
2. 检查关键主张是否与实际实验一致，重点看数据与划分、比较公平性、指标方向、实验预算、消融、统计不确定性、泄漏、替代解释和可复现性。先确认问题确实存在，再判断其影响。
3. 对创新性和引用作有边界的判断：核验近邻论文的实际方法、条件和版本；未访问全文或未完成检索时报告证据缺口，不根据标题宣布重复或首创。
4. 把问题分为阻碍判断、主要问题、次要问题和建议。每项给出位置、可观察证据、对结论的影响、可执行的核查或修改建议；避免按数量凑意见。
5. 汇总作者需要优先处理的事项、尚未核验的内容和审查范围。审稿意见是作者侧诊断，不能冒充真实审稿人或期刊决定，也不能承诺录用。

保持只读；不自动改写原稿或运行实验。作者要求修改时，由写作负责人在授权范围内处理，再核对科学内容。输出格式可参考 [审查记录模板](references/review-template.md)。
