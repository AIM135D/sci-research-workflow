# SCI 文献检索与证据整理

先明确研究问题、领域、时间范围、需要的文献类型和交付深度。复用作者已提供且仍适用的证据，针对问题选择可用的学术索引和原始论文页面；检索范围、工具和访问权限不足时说明缺口。未公开的想法、稿件或数据，未经相应授权不得发送到外部服务；查询时尽可能使用不含敏感细节的关键词。

## 操作步骤

1. 将问题拆成机制、任务、数据和评价条件，并生成必要的同义词；按需覆盖近期工作、最接近的先行方法和相关基础文献。不要用固定篇数代替检索质量。
2. 记录数据库或站点、检索式、日期、筛选条件和失败查询。优先核对期刊、会议、作者发布的原文或预印本；相关工作可以从其他可靠索引发现。
3. 对候选记录标题、作者、年份、发表状态、DOI 或稳定链接，去重并区分预印本与正式版本。适用时用独立来源交叉核验元数据；来源实际上共用上游数据时不能当成独立验证。
4. 明确读到了标题、摘要、全文还是代码。只有看过方法及其条件，才能对具体机制做对应判断；仅凭标题、摘要或数据库字段不能断言方法细节或性能。
5. 对每项与任务有关的论断，记录来源中可定位的证据、相关条件、支持程度和仍未知的信息。不可访问的原文标为未核实；不把检索无结果写成“首创”。

按用户需要输出文献清单、证据矩阵或对比表；为每条结论提供可回溯的链接和阅读层级。不要编造文献、作者、DOI、数据或发表状态；撤稿、版本和发表情况按可用来源及查询时间如实报告。可选记录格式见 [证据记录模板](references/evidence-record.md)。
