# 文献与主张记录模板

以下字段供按需复制。缺失信息填写 `未知`；不要把占位符当成真实论文或检索结果。

| 字段 | 内容 |
| --- | --- |
| 研究问题与用途 | 待填写 |
| 来源、检索式及日期 | 待填写，包括筛选条件和失败查询 |
| 标题、作者、年份、版本 | 待核验 |
| DOI 或稳定链接 | 待核验 |
| 阅读层级 | 标题 / 摘要 / 全文 / 代码 / 无法访问 |
| 论断及原文位置 | 待核验，记录节、图、表或页码 |
| 方法与比较条件 | 待核验，记录数据集、基线、指标和设置 |
| 支持程度 | 支持 / 部分支持 / 证据不足 / 存在冲突 |
| 版本、局限与缺口 | 待填写 |

确认书目资料属于元数据核验；只有读取并核对对应正文，才能评价论文是否支持具体论断。
