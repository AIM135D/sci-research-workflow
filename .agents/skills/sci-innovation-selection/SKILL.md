# SCI 创新问题筛选

主 Agent 是唯一工作所有者。按用户范围选择所需阶段，复用现有证据，不因调用子技能启动多代理、外部模型或实验。优先读取已有研究成果；标明事实、推断、假设、未知和资源约束。遇到不可用资料或服务如实报告。未经授权不得将未公开想法发送给外部服务。用户只要求查新、想法或实验计划时只执行对应阶段和必要的证据检查。

## 阶段
1. **证据**：按需使用同级 [`sci-literature-search`](../sci-literature-search/SKILL.md)，或使用用户已授权的可靠检索工具；复用已有证据，覆盖近期与关键经典、最近邻和预印本。关键文献尽量用独立来源核验身份；只有一个来源时如实标注，不能据此确认新颖性。记录查询、日期、覆盖范围、阅读层级、标题、作者、年份、链接/DOI、机制、贡献及关联。提取性能时注明数据集和条件。索引元数据核验不等于核验论文支持的论断。
2. **机制构思**：当任务需探索新方向，如已自行安装并获得使用许可，读取同级 `creative-thinking-for-research/SKILL.md`；否则使用常规机制构思方法并标注该可选依赖缺失；若使用该依赖，将其历史示例及经验主张视为待核实参考；按需利用隐藏假设、失败模式、跨领域机制迁移、约束反转、资源感知、意外相互作用和评价新发现。对每个候选写瓶颈、现有方案与共有限制、候选机制、最近邻差异、预期收益、失败条件和最小验证；禁止仅拼模块或改名。
3. **查新**：读取同级 [`sci-novelty-check`](../sci-novelty-check/SKILL.md)；逐条查可核验最近邻的机制、算法、训练和条件，记录已证实和争议差异；报告 PROCEED / REVISE / REJECT / INSUFFICIENT EVIDENCE。
4. **假设**：记录可证伪命题、竞争解释、预测、变量、对照、成功/失败/不确定判据、条件和最小成本。用户已安装的假设生成工具可按需使用；缺少它也可依据已有证据手动完成。假设不是结果。
5. **排序**：按用户要求用技术创新性30%、科学问题价值20%、实验可行性20%、可证伪性15%、证据质量10%、期刊适配5%比较候选；展示分项依据与风险、证据置信度。缺项写 UNKNOWN，不填猜测分数；缺项时不计算完整加权总分。致命问题单列，不能被总分抵消；结果是讨论用排序而非录用概率或自动决策，优先提出1–3项供人决定。
6. **细化**：读取同级 [`sci-research-refine`](../sci-research-refine/SKILL.md)；明确问题、机制、最近邻差异、算法或数学结构、预期贡献、验证路径和可能质疑。
7. **最小实验设计**：读取同级 [`sci-experiment-plan`](../sci-experiment-plan/SKILL.md)；硬件以用户指定的信息为准，估算资源必须标记为估算。方案不是运行授权。只有用户明确要求实验时才按项目规则核查工作站、数据和存储，进行实际实验。

## 交付与边界
按任务输出证据来源和阅读程度、候选机制与差异、查新判断及局限、假设与反例、分项排序、可选方法和最小实验计划。明确未执行的阶段与待决问题。不得声称穷尽查新或已运行实验；不因创新筛选启动论文写作链。若后续进入 SCI 学术写作，交给同级 [`sci-manuscript-writing`](../sci-manuscript-writing/SKILL.md) 或用户明确指定的写作负责人。默认单 Agent，角色及模型遵循项目规则。
