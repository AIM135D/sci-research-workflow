# SCI 论文写作与润色

作为本次写作的唯一负责人，先确认目标语言、交付范围、已有稿件或作者提供的证据。用作者材料确定事实；缺失的结果、引文、基线、实验条件和图表信息标记为待补充，不自行编造。保护公式、单位、数值、术语、引用、比较对象、方向、否定、适用条件、负面结果和有意义的不确定性。

## 选择模式

| 请求 | 执行 | 范围边界 |
| --- | --- | --- |
| 局部润色 | 修改用户指定的段落并对照原文 | 不自动检索、重写全文或改变科学结论 |
| 起草或较大改写 | 根据作者提供的证据组织请求范围内的正文 | 证据不足处标注缺口；实质性科学解释需作者确认 |
| 中译英 | 先保义翻译，再单独进行一次英文学术表达检查，最后逐项比对原文 | 用户要求逐字直译时不做语言风格重写 |
| 审稿回复 | 将意见、作者证据和实际修改逐条对应 | 未完成的修改或实验写明状态，不冒充已经完成 |
| 只读诊断 | 交给同级 [`sci-peer-review`](../sci-peer-review/SKILL.md) | 不改稿；如需落地修改，先取得相应授权 |

SCI 论文起草、改写和润色默认先交付请求范围内的中文稿，等待作者决定是否启动英文阶段。用户明确要求英语写作、翻译或润色时直接按该范围执行；明确要求的直译和只读范围优先。用户已有项目规则指定不同语言顺序或写作负责人时，遵循适用的用户和项目指令。

## 写作与核查

1. 明确段落功能：背景、问题、方法、观察、解释或限制。只写材料能支持的内容，避免把相关性写成因果或把假设写成结果。
2. 先准确完成内容，再做一次与语言相符的表达检查：让主体、动作、比较对象和条件清楚，删除空泛铺垫、重复限定和无信息套话。长句、被动语态或必要的不确定性可保留。
3. 保留重要的负面结果、混杂因素、统计不确定性、适用条件、伦理与 AI 使用披露。直接表达不等于放大贡献，也不意味着隐瞒弱结果。
4. 逐段对照修改前后的保护项。中译英还需检查术语、数据集、图表、公式、引用、否定和因果力度；无法确认的内容保持原意并标记，不为流畅而补造。
5. 按范围交付正文及必要的简短说明；指出需要作者核实的实质性疑点。只读任务交付问题清单。完整投稿要求和 AI 政策须核对目标期刊的现行官方规定。

按需使用 [保护项与编辑示例](references/protected-editing.md)。本 Skill 不承诺录用、检测器分数或真实性自动认证；作者负责最终稿件。
