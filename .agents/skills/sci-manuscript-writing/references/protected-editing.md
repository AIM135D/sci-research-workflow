# 编辑前后的科学一致性

将关键句拆成“研究对象或数据集、方法、比较对象、指标、方向与数值、条件、范围和不确定性”，再比较编辑前后是否一致。对于翻译，逐项核对中英文对应内容。引用存在与引用支持某个论断是两项不同检查；如果只看过标题或摘要，应如实标注。

## 虚构的润色示例

原句：“在所测试的数据集上，方法 A 的平均延迟低于基线 B，但在数据集 C 上准确率有所下降。”

可改为：“在所测试的数据集上，方法 A 的平均延迟低于基线 B；但在数据集 C 上，其准确率下降。”

这两句仅用于展示措辞，A、B、C 并非真实实验。润色后仍保留测试范围、比较对象和准确率下降。不能改为“方法 A 全面优于基线”，也不能把未给出的降幅、显著性或原因补进句子。

## 翻译检查

- `at most`、`approximately`、`only`、`without` 以及中文中的“仅”“约”“不超过”等限定需要保留。
- 延迟下降、吞吐量上升、显存占用和逻辑缓存大小属于不同指标；不能互换。
- 对没有给出数字、统计检验或实验条件的陈述，保留未知，不补造。
- 摘要、正文、图表标题和结论引用的模型名称、图表编号和比较方向应一致；涉及不同段落的修改须在授权范围内。

这份清单帮助发现偏差，不能替代作者对语义、原始数据和引用的核查。
