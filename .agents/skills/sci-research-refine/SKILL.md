# SCI 单 Agent 方法细化

方法参考 [ARIS research-refine](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep/blob/main/skills/research-refine/SKILL.md) 的问题锚点和简洁机制设计；不采用其跨模型循环、模型固定值或自动外部工具。

冻结用户的研究问题、应用条件和可用证据，区分未知。提出最小足够机制，说明输入输出、关键数学/算法与数据流、训练或推理策略、与最近邻的具体差异、可证伪预测、预期贡献和代价。记录关键假设、失败条件、实现难点、最简基线及可能审稿质疑。没有依据的机制标为待验证；不制造实验结果，不把工具强度或某模型视作前提。输出明确问题、方案、差异表、风险和最小验证交接。
