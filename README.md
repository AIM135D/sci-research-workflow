# SCI Research Workflow

一个以证据和可证伪实验为中心的科研工作流，提供创新筛选 Skill 与六个可选的 Codex 专业角色。默认单 Agent；仅在用户明确要求时启动多代理。研究者负责最终判断。

## 内容

- `.agents/skills/`：创新筛选、查新、机制细化和最小实验设计。
- `.codex/agents/`：文献、创新、对抗审查、实验设计、实验执行、论文审计六个角色。
- `AGENTS.md`：可用于项目的精简指令；请按实际环境审阅。

## 使用

1. 将所需文件复制到目标项目对应位置；事先备份已有同名文件，检查 Codex 客户端是否支持项目配置、角色和 Skill。
2. 审阅 `AGENTS.md` 和角色限制，选择可用的模型及计算预算。实际功能取决于客户端、账户和工具权限。
3. 描述研究问题及所需阶段。若需要多代理，明确提出启动，并提供或授权选择各角色模型。实验必须另行获得授权。

## 依赖及边界

创新筛选入口引用可选的 `paper-lookup`、`ligphidonk__real-literature-trace`、`hypothesis-generation`、`creative-thinking-for-research`、`chinese-humanizer` 等本地 Skill；它们未包含在本仓库。使用者应自行核对来源、许可证和安装情况；不可用时须报告或采用经用户认可的替代方法，不能声称已运行。`<CODEX_HOME>` 为目标环境 Codex 目录的占位符，使用时需自行解析。角色配置中的硬件及存储规则需依据目标环境修改。

部分查新与研究细化方法参照原文件中链接的 ARIS 工作；引用不表示该项目或作者为本项目背书。该仓库不包含训练数据、论文、实验结果、账户、凭据或模型。模型输出和审稿仅为研究辅助，不代表科学结论或期刊决定。
