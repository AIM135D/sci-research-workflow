# 示例任务

下列提示词中的方括号是待用户填写的占位符，没有内置真实论文、数据或结果。开始前请提供有权使用的材料，并根据任务说明是否允许联网。

## 1. 文献检索

```text
使用 sci-literature-search，围绕 [研究问题] 检索 [时间范围] 的相关工作。
重点比较 [任务或机制]，同时识别必要的基础工作。请记录检索来源、日期、
论文版本、链接和阅读层级；不能访问的全文标为未核实，不要编造 DOI。
```

适合得到可回溯的论文清单。若要提出方法创新，下一步还需核查最接近方法的具体机制、条件和证据，不能只比较标题。

## 2. 创新查新

```text
使用 sci-novelty-check，对我提供的 [候选机制] 和 [已核验论文清单] 做比较。
逐项检查输入、核心机制、训练方式和适用条件；给出差异证据、未解决问题和判断。
未公开的方案细节不要发送给外部服务。
```

若关键论文只有摘要或无法访问，应保留证据不足的结论。新方法是否值得继续还取决于可检验假设和实验成本。

## 3. 最小实验设计

```text
使用 sci-experiment-plan，为 [候选假设] 设计最小区分性实验。
可用资源为 [硬件、时间和数据]，请列出强基线、评价指标、关键对照、
可能的泄漏、停止条件及复现记录。现在只需要计划，不执行实验。
```

## 4. 中文润色与中译英

```text
使用 sci-manuscript-writing，只润色以下中文段落：[粘贴段落]。
保留数据、引用、限定和负面结果；对缺少依据的句子提出问题。
```

```text
使用 sci-manuscript-writing，将以下内容译成英文学术表达：[粘贴段落]。
完成翻译后单独检查行文，再与中文核对公式、数值、引用、否定和比较方向。
```

如果只需要直译，请明确写“逐字直译，不调整行文风格”。

## 5. 作者侧只读审查

```text
使用 sci-peer-review，只读审查我有权提供的稿件 [文件]。
重点检查主要结论与图表、基线和统计结果是否一致；每条问题给出位置、
依据、影响和建议。没有提供的数据或没有读到的引用请标为未知。
```
